# 스마트해상물류 역대 수상작 분석 및 보고서 반영

## 검토 범위

- [울산항만공사 실무형 해상물류 일자리 지원사업 — 스마트해상물류경진대회 수상작](https://usmac.or.kr/prog/award/kor/01/sub02_02_01/list.do)
- 공개 페이지에는 2023~2025년 수상작 46건과 작품 소개, 첨부파일 바로보기 항목이 확인됨.
- 공개 첨부자료는 발표·소개 성격이므로, 이를 그대로 베끼지 않고 **문제 설정·기능 증빙·영상 구성 방식**만 참고한다.

## 집중 참고 수상작

| 연도·수상 | 작품 | 공개 소개에서 확인되는 구성 | 사일로봇 반영점 |
|---|---|---|---|
| 2025 대상 | 친환경 수소 선박 시뮬레이터 | 하나의 시스템 흐름(생산→추진→운항 데이터)을 플랫폼으로 제시 | 기구·제어·영상·안전을 나열하지 않고 `점검 임무 흐름`으로 연결 |
| 2025 금상 | 스마트 계류줄 관리 시스템 | 로드셀·엔코더·자동 모터 제어·기상정보·대시보드의 통합 | 센서값이 화면 표시에서 끝나지 않고 위험 판단·정지·기록까지 이어지게 제시 |
| 2025 장려 | 항만시설 현장 안전 지킴이 로봇 PORTY | 자율 순찰, CV·센서 이상감지, 실시간 모니터링 | 기능별 짧은 실제 시연과 관제 화면을 대응시켜 영상 구성 |
| 2024 금상 | AI 기반 스마트 해변 자율청소로봇 | 자율주행·AI 인식·관리 데이터의 현장문제 적용 | AI는 실제 추론이 있을 때만 결과로 제시하고, 없으면 개발계획으로 구분 |
| 2024 장려 | SLAM 기반 자율주행 지게차 | 물류 현장 자동화 문제와 무인 운반 장치의 연결 | `항만 사일로 안전점검`이라는 좁고 구체적인 사용자·현장을 유지 |

## 수상작에서 확인한 작성 원칙

1. **문제는 현장 하나로 고정한다.**
   - 사일로봇은 ‘모든 철제 구조물 로봇’보다 `항만 사일로 내·외부의 위험 점검`을 먼저 설명한다.
2. **핵심 장치는 직접 만든 구조로 보여준다.**
   - 궤도 프레임·구동륜·궤도·힌지·장력조절부를 직접 CAD 설계·3D 출력한 과정을 CAD 분해도와 실물 사진으로 증명한다.
3. **센서→판단→행동의 한 흐름을 만든다.**
   - 영상·IMU·3점 거리를 제시할 때는 `상태 확인 → 이상 감지 → 정지 래치 → 기록 → 수동 재개` 순으로 설명한다.
4. **완료와 계획을 엄격히 분리한다.**
   - 실제 확인된 무선 모터 제어·비상정지·CSI 실시간 영상은 증거 화면을 사용한다.
   - IMU·거리 자동정지, HIL 반자율, AI 균열탐지는 실제 시험 전 `개발 예정/개발 중`으로 표기한다.
5. **영상은 기능 설명보다 반응 증명에 시간을 쓴다.**
   - 조작 화면만 보여주지 않고 `RPi4 조작 → 모터 반응`, `CSI 장면 → RPi4 화면`, `외란 → 경고/정지`를 한 화면 또는 연속 컷으로 연결한다.

## 사일로봇의 제출 메시지

> 상용 로봇을 개조한 것이 아니라 항만 사일로의 곡면 철제 벽면을 목표로 궤도·관절·서스펜션·자력 구조를 직접 설계했다. 작업자 투입 전 원격으로 벽면 상태를 확인하고, 실제 검증된 무선 구동·비상정지·실시간 영상 위에 센서 안전판단과 점검기록을 단계적으로 통합하는 안전점검 플랫폼이다.

## 보고서 반영 완료 항목

- `I. 작품 개요 / 작품 소개`: 항만 사일로 위험점검·직접 설계 전용 플랫폼을 첫 문장에 배치
- `I. 작품 개요 / 차별성`: 상용 자력 크롤러의 실제 사례를 인용하되, 성능 우위 주장이 아니라 사일로 맞춤 기구·사전 안전점검 역할로 구분
- `II. 작품 내용 / 주요 적용 기술`: 가변 자력·곡률 적응·실제 제어/영상 검증·센서 안전 실증 계획을 분리 표기
- `III. 수행 내용 / 애로사항`: 2025년 궤도 파손→재설계를 학습·개선 근거로 유지
- `시연영상 콘티`: 기능별 실제 반응 증명과 향후 계획 분리 원칙 반영
