# 시연용 최소 배선도

거리센서·IMU·배터리 ADC를 아직 달지 않고 **영상과 모터 구동을 촬영하기 위한 현장 요약본**이다.
핀 단위 전체 배선과 전기 주의사항의 단일 정본은 [[2. 하드웨어/05. 배선도]]다.

## 1. 최소 구성

```text
[USB 보조배터리] → RPi4 + 7인치 화면
                         │ Wi-Fi/Tailscale (WebSocket 8765·RTSP 수신)
                         │
[5V 전원/UPS] → Jetson Nano B01 ← CSI 리본 ← IMX219 카메라
                         │ USB ST-LINK (전원+통신, /dev/ttyACM0)
                         ▼
                    STM32 NUCLEO
        ┌────────────────┼────────────────┐
        │ PWM·방향 12선  │ 엔코더 A/B×2  │ 공통 GND
        ▼                ▼                ▼
    DFR0601 ×2       좌 M1·우 M3       스타 접지
        │
      모터 4개

[외부 전원] → Orin Nano ── 네트워크 ──→ RPi4   (AI 촬영 때만, 없어도 주행 가능)
```

### 시연에서 빼도 되는 것

| 장치         |    수동 모터 촬영 | 짧은 자율 경로 촬영 | 비고                                       |
| ---------- | ----------: | ----------: | ---------------------------------------- |
| 거리센서 3개    |       제외 가능 |       제외 가능 | `demo-drive`가 거리 게이트 우회                  |
| WT901C IMU |       제외 가능 |       제외 가능 | 현재 오도메트리 기본은 엔코더 `encoder_alpha=1.0`     |
| 배터리 분압 ADC |       제외 가능 |       제외 가능 | 펌웨어를 `BATTERY_MONITOR=0`으로 빌드. 전압은 직접 확인 |
| 엔코더 2개     |       제외 가능 |      **필수** | 수동 조작에는 없어도 되지만 자율 위치 추정에는 필요            |
| CSI 카메라    | 영상 불필요 시 제외 |   시연영상에는 권장 | RTSP 화면 촬영용                              |
| Orin Nano  |       제외 가능 |       제외 가능 | AI 탐지가 필요한 장면에서만 사용                      |

## 2. 모터 전원

```text
LiPo #1 (+) ── 20A 퓨즈 ── 스위치 ── DFR0601 #1 P+  → 좌 M1·M2
LiPo #1 (−) ───────────────────────── DFR0601 #1 P−

LiPo #2 (+) ── 20A 퓨즈 ── 스위치 ── DFR0601 #2 P+  → 우 M3·M4
LiPo #2 (−) ───────────────────────── DFR0601 #2 P−
```

- LiPo 두 팩 음극, 드라이버 GND, STM32 GND는 굵은 선의 **스타 접지 한 점**으로 묶는다.
- 모터 전원과 모터선은 빵판에 연결하지 않는다.
- 배터리 `+`에서 퓨즈까지 선은 가능한 짧게 한다.
- Nano는 5V 전원/UPS, RPi는 USB 보조배터리, Orin은 외부 전원을 사용한다.

## 3. STM32 → DFR0601 제어선

DFR0601 #1은 좌측, #2는 우측이다. 각 입력에는 10kΩ 풀다운을 권장한다. **핀 번호는 이 문서에
복사하지 않는다.** 현장에서는 반드시 [[2. 하드웨어/05. 배선도]] §3의 단일 정본 표를 연다.

```text
NUCLEO 3V3 ──→ DFR0601 #1 VCC, #2 VCC
NUCLEO GND ──→ DFR0601 #1 GND, #2 GND
12V PSU +V/−V ──→ 각 DFR0601 P+/P−
```

2026-08-24 실물 확인값은 **제어 VCC 3.3V**다. `E5V`는 NUCLEO 외부전원 입력이며 드라이버
전원 출력이 아니다. `STATE` 적색 LED는 보드 전원/상태 표시이고, 채널 LED는 실제 출력 때 켜진다.

## 4. 엔코더

모터 커넥터 1·2번은 모터선이고 3~6번이 Hall 센서다.

```text
WGM40 6핀
1 MOTOR+  → 드라이버 모터 출력
2 MOTOR−  → 드라이버 모터 출력
3 Hall GND → STM32 GND
4 Hall VCC → STM32 3.3V  (5V 금지)
5 Hall A   → A 입력
6 Hall B   → B 입력
```

Hall A/B의 STM32 연결 핀은 [[2. 하드웨어/05. 배선도]] §4만 따른다.

현재 코드 규약은 양쪽 모두 **카운트 감소 = 전진**, 좌우 `meters_per_count` 모두 음수다.

## 5. Nano·카메라·관제 연결

```text
STM32 ST-LINK USB ──→ Nano USB       /dev/ttyACM0, 115200 bps
IMX219 CSI 리본 ────→ Nano CSI       RTSP 720p30
Nano Wi-Fi/Tailscale ─→ RPi4         ws://100.74.141.112:8765
RPi4 ← Nano RTSP                     rtsp://100.121.144.38:8554/robot
```

IMU를 다시 연결할 때는 TX/RX를 교차한다. 정확한 전원·GPIO 핀 번호는
[[2. 하드웨어/05. 배선도]] §7-1만 따른다.

## 6. 시연 전 도통·방향 체크

- [ ] 모든 전원 OFF 상태에서 `P+ ↔ GND`, `3V3 ↔ GND` 단락 없음
- [ ] 엔코더 Hall VCC 3.3V 확인
- [ ] 두 드라이버·STM32·두 배터리 GND 공통
- [ ] STM32 USB만 연결했을 때 모터 출력 정지
- [ ] Nano에서 `/dev/ttyACM0` 확인
- [ ] 궤도를 띄운 뒤 모터 전원 ON
- [ ] M1·M2가 같은 방향, M3·M4가 같은 방향
- [ ] 전진 시 좌우 궤도가 같은 진행 방향
- [ ] `turn=+`에서 좌 전진·우 후진
- [ ] 대시보드 비상정지 시 즉시 PWM 0
- [ ] Nano 프로세스 강제 종료 후 300 ms 안에 PWM 0

실행 명령과 복귀 절차는 [[10. 장치별 동작 및 명령어]] §3·§6을 따른다.
