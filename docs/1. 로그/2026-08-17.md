## 종합조사 문서·해운물류 서식 수령 → 보고서 초안 착수

- 사용자가 `사일로봇_종합조사_최종본_링크.pdf`(15p, 시장·규제·BM 종합조사)와 해운물류
  서류 일체 zip(제반규정·안내사항·개발보고서 HWP 서식)을 제공.
- **PDF 한글이 추출되지 않는 문제**: 이 문서들은 폰트에 ToUnicode 매핑이 없어 `pdftotext`로
  한글이 전부 탈락했다(볼트에 기록돼 있던 이 PC의 알려진 제약). `scoop install poppler`로
  `pdftoppm`을 설치해 **페이지를 이미지로 렌더링한 뒤 직접 읽는 방식**으로 우회 — 완전히 읽힘.
  **다음에 한글 PDF를 다룰 때도 이 방법을 쓸 것.** HWP 서식은 본문이 압축돼 있어 미리보기
  텍스트 스트림에서 표지·요약본·`I. 작품 개요 1. 작품 소개 / 2. 개발 배경 및 필요성`까지만
  추출됐다 — 나머지 소제목은 한글에서 직접 열어 확인 필요.
- 종합조사 문서에서 건진 것: 밀폐공간 질식사고 통계(10년 348명 사상, 질식재해 사망비율

  별표18이 곡물 사일로를 밀폐공간으로 명시, 2024년 중대재해처벌법 확대(5~50인 사업장, 처벌

## 학교 실기 — 네트워크 우회 (임시, 설계 변경 아님)

학교 WiFi는 라파·젯슨 둘 다 붙지 못했고(WPA2-Enterprise 추정), 젯슨 B01은 무선랜카드가
아직 도착하지 않아 내장 무선이 없다. 폰 핫스팟은 라파만 붙는 상태.

**오늘 한정 우회**: 젯슨 ↔ 라파를 **랜선 직결**로 연결.
- 젯슨 `192.168.50.10/24`, 라파 `192.168.50.20/24` (게이트웨이 미지정 — 라파의 WiFi 기본
  경로를 건드리지 않기 위함)
- 대시보드 `연결 설정`에 이 주소 입력, 젯슨 `dashboard_bridge`는 `ws://192.168.50.20:8765`
- 재빌드 불필요 — 주소를 소스에 두지 않고 화면에서 바꾸도록 한 결정([[02. 결정로그]])이
  그대로 효과를 봤다

**주의: 이건 인터넷이 없는 환경에서의 임시 경로지 통신 구조 변경이 아니다.**
확정 설계는 여전히 **Tailscale 기반 무선**이다 — 로봇이 벽면을 주행하는데 유선을 달 수 없다.
다음 세션은 이 IP를 확정 스펙으로 오해하지 말 것. 랜카드 도착 후에는 Tailscale로 복귀한다.

오늘 얻은 부수 정보: WebSocket·RTSP 모두 로컬 프로토콜이라 **인터넷 없이도 통합 시험이
가능하다**는 게 확인됐다. 시연장이 폐쇄망일 때의 대비책으로도 유효하다([[08. 남은과제]] 8절).
