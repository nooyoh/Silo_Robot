## Orin Nano Super 1차 구현 (구술·작업 그대로)

- 사용자가 "뭐할건지부터 말하고 ㄱㄱ"라고 하여 구현 범위를 먼저 설명한 뒤 착수.
- 작업공간에 Orin 레포가 없어 `orin-nano-super/` 생성.
- `inference/`: Nano B01 RTSP(`rtsp://100.121.144.38:8554/robot`) 수신, YOLOv8s/TensorRT 추론,
  RPi4 대시보드(`ws://100.74.141.112:8765`)로 정규화 박스 좌표 전송, JSONL 로그 저장.
- `train/`: Victus RTX 4060용 YOLOv8s 파인튜닝과 ONNX/TensorRT export 스크립트.
- WebSocket 자동 재접속, `hello/orin`, 빈 탐지 목록, `--dry-run`, 좌표 경계 보정 구현.
- PC에 pytest가 없고 Google Drive가 `__pycache__` 생성을 막아, 설치 없이 AST 8파일과 메시지 계약을
  직접 검사해 통과. 실제 데이터 변환·학습·Jetson TensorRT·실기 통합 시험은 아직 하지 않음.
- 같은 Google Drive 권한 문제로 `orin-nano-super/.git` 생성도 거부되어 로컬 Git 초기화는 실패.
  코드 디렉터리는 완성됐으며, 추후 GitHub 빈 레포를 정상 경로에 clone해 파일을 옮겨 연결해야 함.

## 날것 기록
- 라즈베리파이4 대시보드의 1차 Qt Quick 앱을 Wayland 세션에서 실행했다.
- 사용자는 기존 화면이 둥글고 귀여워 보이며 학생 프로젝트 같다고 피드백했다. 항공기 조종석,
  차량 계기판, Home Assistant 모니터링, 로봇 관제 화면 이미지를 참고로 제시했다.
- 중앙 영상과 주변 계기를 쓰는 디지털 조종석 방향으로 화면을 다시 구성했다.
- 사람이 읽고 누르는 문구는 한글을 쓰되, 장비 상태와 기술 라벨은 영문 코드로 남기는 방향을 정했다.
- 사용자는 IP·RTSP 주소 등을 코드에 고정하지 않고 화면에서 입력·저장한 뒤 자동으로 다시 연결되며,
  필요할 때 다시 수정할 수 있게 해 달라고 요청했다.
- `연결 설정` 화면에 대시보드 Tailscale 주소, RTSP URL, WebSocket 포트를 두고 저장값을 다음 실행에
  재사용하도록 구현했다.
- 기존 조종석 화면도 청록 네온·격자·원형 계기가 저가 SF HUD처럼 보인다는 추가 피드백을 받았다.
- 화면을 다시 전면 교체했다. 무광 차콜/웜그레이, 선형 주행·조향 축, 큰 비상정지, 중앙 영상,
  제한된 안전색으로 구성한 산업 운용 콘솔로 변경했다.
- `--demo`에서 가짜 `CRACK 93%` 결함 박스를 띄우지 않게 고쳤고, 데모 상태를 화면에 표시했다.
