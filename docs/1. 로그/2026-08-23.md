# 2026-08-23 작업 로그

## 사용자 확인 사항

- Google Colab Pro를 사일로봇 학습 환경으로 사용하기 위해 구매함.
- 해당 비용은 스마트해운물류 사업비로 지출함.

## 후속 확인 필요

- 결제 금액, 결제일, 영수증 또는 결제 증빙
- 기존 스마트해운물류 예산 집계에 포함되었는지 여부
- 실제 모델 학습을 시작했는지 여부와 사용 데이터셋

## 문서 작성 원칙

- 결제 금액과 집계 포함 여부가 확인되기 전까지 예산 합계는 변경하지 않음.
- Colab Pro는 구매가 확인된 개발환경으로 기록하되, 모델 학습 완료나 성능 검증 완료로 표현하지 않음.

## SOL Extra High 전면 코드 관제

- 4개 로컬 저장소의 기준 브랜치와 기존 테스트를 확인하고 AI 학습/실추론 외 운용 코드를 재검토했다.
- STM32: `0xBE` 2팩 배터리 텔레메트리, 1/5 이론 분압, 유효성 안정화, 10.5V 경고,
  9.9V 3회 연속 저전압 자체 정지, 10.2V 회복 히스테리시스, 저전압 중 해제 거부를 구현했다.
  회로 미배선 상태의 floating ADC가 가짜 전압이 되지 않도록 기본은 `BATTERY_MONITOR=0`이다.
- 엔코더: TIM 입력필터 4, 50ms당 5000 count 초과 점프 거부, 이벤트 flag 전달을 추가했다.
- Nano: 이론/STL 시작값을 양쪽 음수 scale·0.294m track width로 통일하고, 보정 보고서가 부호를
  잃던 문제를 수정했다. pose/safety stale·wheel count stale·4초 무진행이면 자율 명령을 중단한다.
- 커버리지 플래너의 lane 수 off-by-one을 수정해 요청한 간격보다 실제 차선 간격이 넓어지지 않게
  했다. 회전비용 0.5m 이론값을 포함해 가로/세로 후보를 선택하며 plan id는 밀리초까지 구분한다.
- RPi4: 안전정지 자동기록과 plan/waypoint/pose/센서/배터리/AI 박스 메타데이터를 구현했다.
  로봇·Orin이 3초 stale이면 오래된 안전상태/결함 박스를 폐기하고 조작을 막는다.
- Orin: OpenCV를 지연 import하고 JetPack 버전별 RTSP timeout API 폴백, NaN·퇴화 박스 제거,
  class 이름 fallback, 부팅 서비스 설치 스크립트를 추가했다. 실제 engine이 없으면 자동실행 설치를 거부한다.
- 검증 결과: STM32 실제 C 단위시험 + 자율 폐루프 32 + 통신·안전 31 = **63개 전부 통과**,
  Nano 패키지 계약 4개 통과, Orin Python compile/핵심 계약 통과, 모든 셸 스크립트 `bash -n` 통과.
  RPi4 native Qt build, ARM 펌웨어 cross-build, 실제 배선·보정·주행은 장치에서만 가능해 남겨뒀다.
- GitHub `main` push 완료: `stm32-controller@c803783`, `jetson-nano-b01@ddf1b59`,
  `rpi4-dashboard@7a5c99c`, `jetson-orin-nano@5afc04d`.
- 첫 안전 텔레메트리 수신 전 Nano 브릿지와 RPi 관제 화면 모두 정지 래치로 시작하도록
  fail-closed 기본값을 적용하고 회귀 검사를 추가했다.
- 장치별 역할·복붙 명령 정본과 시연용 최소 배선도를 추가했다. Nano에는 `DEMO` 대화형 확인을
  요구하는 `demo-drive`를 추가해 거리·IMU 자동판단과 armed 자율 게이트만 우회하며, 비상정지·
  STM32 정지 래치·300ms 통신 타임아웃·활성화된 저전압 보호는 유지한다. 기존
  `bench-autonomy`는 `BENCH` 확인을 요구하는 호환 별칭이다.
- 후속 새 시선 검토에서 **저전압 회복 후 해제 교착**을 발견했다. STM32의 bit3는 과거 저전압
  정지 래치라 해제 명령 전까지 남는데, Nano가 bit3 자체를 이유로 해제를 막으면 영구 교착이었다.
  현재 두 팩이 10.2V 이상인지로 해제 조건을 바꾸고 저전압/회복 양쪽 계약시험을 추가했다.
