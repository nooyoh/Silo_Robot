## 팀
- 2025년과 2026년 팀 동일 — 팀원, 멘토 모두 유지.
- 2025년 팀 전원 학부 3학년, 소프트웨어 담당은 컴퓨터과학과 출신(임베디드 비전공).
- 2026년 팀은 각자 다른 임베디드 부트캠프를 수강해 임베디드 지식 보강.
- **학생 팀원 5명 + 멘토 1명** (2025=2026 동일). ACK2025 저자 명단에는 멘토(박철훈)도 공저자로
  같이 올라가 있어 6명으로 보였으나, 실제 학생 팀원은 5명 — [[90. 공모전메모]] 저자 표기와
  혼동 주의.
- **역할 분담**:
  - 안민철 — 팀장 / PM / 소프트웨어
  - 조경찬, 김상우 — 하드웨어 설계 및 조립 (기계공학과)
  - 송관웅 — 전기/전자전공, 배선 등 전기 쪽 (하드웨어-소프트웨어 연결 역할)
  - 이호윤 — 소프트웨어, 특히 영상처리 위주 (컴퓨터과학과)
- **멘토**: 박철훈 / ㈜피비아이 대표이사 / 온·오프라인 혼용, 최소 월 1회 멘토링

### 2026-08-18 통합 작업

- RPi 관제 콘솔, Jetson Nano, STM32, 모터 4채널을 연결하여 조작 명령과 텔레메트리 흐름을 통합 확인했다.
- Nano의 CSI 카메라 RTSP 720p30 영상을 RPi 관제 화면에서 수신하는 것을 확인했다.
- 모터 4개의 무부하 회전과 방향 전환을 확인했으며 최종 프레임 장착 상태의 주행 검증은 별도 과제로 남겼다.
- 하드웨어 의존 작업과 소프트웨어 단독 검증을 분리하여 장비가 없는 동안에도 통신·경로·관제 로직을 검증하도록 진행했다.

### 2026-08-21 통합·오류 분리

- RPi 관제 화면의 터치 조작, 영상 표시, 상태 표시, 경로 생성, 점검 기록 조회 기능을 통합 확인했다.
- 엔코더 부호, 경로 추종 조향 부호, 계획 좌표와 오도메트리 좌표의 기준점 불일치를 순차적으로 분리해 수정했다.
- 장치 없이 재현할 수 있는 검증 항목을 테스트 코드로 남기고 실물 확인이 필요한 항목은 별도 체크리스트로 분리했다.

### 2026-08-23 4개 저장소 전면 관제

- AI 학습·실추론을 제외한 STM32–Nano–RPi 운용 흐름을 처음부터 다시 검토하고, 이론 시작값과
  실측 대기값을 분리했다.
- 실제 펌웨어 C를 포함한 오프로봇 검증 63개와 패키지 계약 4개를 통과시켰다. 대형 12×8m
  50-waypoint 경로까지 폐루프 완주하고, 잘못된 부호를 일부러 넣으면 실패하는 역검증을 유지했다.
- 장치 배포 전 코드 완성선과 장치에서만 가능한 native build·배선·보정·실주행을 분리해 인수인계했다.

### 2026-08-22 장치 외 검증

- 장치 외 검증 스위트 52개 항목이 통과했다.
- 거리센서가 아직 연결되지 않은 상태에서도 부팅이 막히지 않도록 자동 시작 설정의 거리센서 필수 조건을 해제했다.
- 최신 수정 코드는 저장소에 반영했으나 Nano와 RPi 실기기에 아직 배포하지 않았으므로 다음 통합 시험 전에 pull·빌드·서비스 재시작이 필요하다.
