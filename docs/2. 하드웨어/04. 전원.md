# 전원

로봇 구동계 전원과 배터리 감시 회로의 정본. 모터 4개를 LiPo 2팩으로 나눠 구동하고, STM32가
두 팩의 전압을 각각 감시해 저전압에서 스스로 모터를 끊는다. 배선·회로는 이 문서를 따르고,
실물에서 달라진 것은 먼저 여기에 반영한다.

관련: [[3. 소프트웨어/01. STM32]] · **핀맵 단일 정본 [[2. 하드웨어/05. 배선도]]** ·
[[05. 부품표]] · [[02. 결정로그]]

## 1. 시스템 구성 및 역할

| 구성 | 역할 |
|---|---|
| **LiPo 배터리 ×2** | 모터 구동용 주 전원. 3S, 완충 12.6V / 공칭 11.1V / 2200mAh 70C |
| **20A 블레이드 퓨즈 ×2** | **배선 단락 시** 배터리와 회로를 차단. 팩당 1개 |
| **메인 스위치 ×2** | 배터리별 전원 ON/OFF. **정비·보관 시 최종 차단용** |
| **DFR0601 ×2** | STM32 제어신호를 받아 모터에 전력 공급. 드라이버 1개가 모터 2개 담당 |
| **모터 ×4** | WGM40-3150-1280E. 12V, 감속비 1/290 |
| **STM32** | 모터 제어 + **배터리 전압 감시·저전압 차단**. 전원은 Nano B01의 USB(ST-LINK)로 공급 |
| **Jetson Nano B01** | 메인 제어기. STM32와 UART(ST-LINK VCP) 통신 |
| **Jetson Orin Nano** | 영상 결함탐지 서버. **로봇 외부에 있고 별도 전원을 쓴다 — 이 전원 계통과 무관.** Nano B01과는 유선이 아니라 네트워크(RTSP)로 연결 |

### 퓨즈의 역할을 오해하지 말 것

**20A 퓨즈는 드라이버를 과부하에서 보호하지 못한다.** 드라이버당 모터 2개가 동시에 스톨하면
13A(6.5A×2)인데, 블레이드 퓨즈는 정격 이하에서 끊어지지 않는다. 즉 스톨이 지속되면
드라이버(정격 12A)가 먼저 죽는다.

그럼에도 퓨즈는 필요하다. **LiPo는 단락되면 수백 A를 쏟아내 배선이 녹고 화재로 이어진다.**
퓨즈의 본업은 그 단락을 끊는 것이다. 드라이버 과부하 보호는 DFR0601 자체 보호회로와 펌웨어
스톨 감지가 담당한다.

### 긴급정지는 스위치가 아니다

물리 스위치는 2개라 한 번에 못 끊는다. **긴급정지는 대시보드 정지 명령 + STM32 정지 래치**가
담당하고, 통신이 끊기면 STM32의 300ms 타임아웃 페일세이프가 마지막 방어선이다
([[3. 소프트웨어/01. STM32]]). 물리 스위치는 정비·보관·최종 차단용으로만 쓴다.

## 2. 부품 및 배선 규격

| 항목 | 규격 | 용도 |
|---|---|---|
| AWG 12 | UL1015 | 배터리 ↔ 퓨즈 ↔ 스위치 ↔ DFR0601, **스타 접지 간선** |
| AWG 18 | UL2468 | DFR0601 ↔ 모터 구동선 |
| AWG 22~26 | 점퍼선 | STM32 ↔ DFR0601 제어신호(PWM·INA·INB), 전압 측정선 |
| 10kΩ ×12 | 1/4W 5% | 제어선 풀다운 (PWM 4 + 방향 8, **전수 적용**) |
| 10kΩ ×10 | 1/4W 5% | 배터리 분압 (팩당 5개 × 2팩) |
| 100nF ×2 | 세라믹 | 분압 노드 ADC 노이즈 필터 |
| 20A 블레이드 퓨즈 ×2 + 홀더 | 32V | 팩당 단락 보호 |
| 토글 스위치 ×2 | 12V 고전류 | 팩당 메인 스위치 |

### 저항 예산 (추가 구매 불필요)

보유 10kΩ **30개** 중 풀다운 12 + 분압 10 = **22개 사용, 8개 여유**.
100kΩ·27kΩ을 따로 살 필요 없다 — 아래 §5 참조.

### 커패시터 예산 (빠듯함)

보유 100nF **10개**. 배터리 분압 2 + 거리센서 6(센서 Vcc 디커플링 3 + RC 필터 3) = **8개 사용.**
여유 2개뿐이므로 잃어버리지 않게 주의.

```text
[Jetson Orin Nano]   로봇 외부·별도 전원 (RTSP 네트워크, 이 전원계통 무관)
        ┊
[Jetson Nano B01] ──────── UART ────────┐
        │ USB 전원 & GND                 │ 명령
        ▼                               ▼
     [STM32] ◄──── ADC #1  ──── 분압 ◄── LiPo #1
        │      ◄──── ADC #2  ──── 분압 ◄── LiPo #2
        │
        │ PWM 4 + INA/INB 8 = 12가닥 (전부 10kΩ 풀다운)
        ▼
  [DFR0601 ×2]
        │
    [모터 ×4]
```

## 4. 전원 배선과 스타 접지

```text
LiPo #1 (+12.6V) ── [20A 퓨즈] ── [스위치] ──┬── DFR0601 #1 VCC
                                             └── 분압 #1 ──→ STM32 ADC #1

LiPo #2 (+12.6V) ── [20A 퓨즈] ── [스위치] ──┬── DFR0601 #2 VCC
                                             └── 분압 #2 ──→ STM32 ADC #2
```

### 스타 접지 (단일점)

```text
[스타 접지 포인트]
   ├── LiPo #1 (−), LiPo #2 (−)      AWG 12
   ├── DFR0601 #1 GND, #2 GND        AWG 12
   ├── 분압 #1·#2 하단 GND            AWG 22~26
   ├── 풀다운 12개 GND                AWG 22~26
   ├── STM32 GND                     AWG 22~26 분기
   └── Jetson Nano B01 GND           STM32 USB를 통해 자동 공유
```

**왜 한 점에 모으는가.** 두 배터리의 (−)는 STM32 GND를 통해 어차피 연결된다(PWM·ADC가
동작하려면 기준이 같아야 하므로 필수다). 그런데 **굵은 접지선이 끊기거나 접촉이 나빠지면
모터 복귀 전류(최대 13A)가 얇은 신호 접지선으로 돌아간다.** AWG22~26은 그 전류를 못 버티고
탄다. 한 점에서 굵은 선으로 확실히 모아야 이 경로가 생기지 않는다.

**스위치는 (+)측에만 있다.** 스위치를 꺼도 (−)는 스타 접지에 계속 물려 있으며, 이는 정상이다.

## 5. 배터리 전압 측정 회로

### 분압비 — 10kΩ만으로 구성

```text
LiPo (+) ── [10k]─[10k]─[10k]─[10k] ──┬──────┬──→ STM32 ADC
              R1 = 40kΩ (4개 직렬)     │      │
                                     [10k]  [100nF]
                                   R2=10kΩ    │
                                       │      │
                                      GND    GND   (스타 접지)
```

- **분압비 = 10/(40+10) = 1/5 정확히** → `V_batt = V_adc × 5`
- 12.6V(만충) → **2.52V** / 11.1V(공칭) → 2.22V / 9.9V(차단) → 1.98V
- 5% 오차 최악(R1 −5%, R2 +5%): 12.6V → **2.73V** — 3.3V까지 여유 확보
- **소스 임피던스 = 40k∥10k = 8kΩ** — ADC에 유리
- 소비 전류 = 12.6V / 50kΩ = **252µA**, 팩당 무시 가능
- 100nF와 R2는 **ADC 노드에서 GND로 병렬**이다 (직렬 아님)

> **왜 100kΩ+27kΩ이 아닌가.** 그 조합도 계산상 안전하지만(최악 2.90V) 100k·27k를 새로
> 사야 하고, 소스 임피던스가 21kΩ으로 높다. 보유 중인 10kΩ만으로 더 낮은 임피던스와
> 딱 떨어지는 1/5 비율을 얻을 수 있어 이쪽을 택했다.

### ADC 채널

배터리 두 팩은 서로 다른 ADC 채널로 읽는다. **정확한 MCU 핀·ADC 채널·헤더 위치는 이 문서에
복제하지 않고 [[2. 하드웨어/05. 배선도]] §6만 따른다.**

**샘플링 시간은 480사이클**을 쓴다(거리센서와 공용 설정).

### 왜 두 팩을 모두 재는가

**궤도 로봇은 회전할 때 좌우 부하가 크게 달라진다.** 한쪽으로 많이 돌면 그쪽 팩이 먼저 닳는데,
한 팩만 감시하면 반대쪽 팩이 셀당 3.0V 아래로 떨어져도 못 잡는다. LiPo는 그러면 영구 손상이다.
팩당 분압 5개 + 캡 1개면 되므로 두 팩 모두 감시한다.

### 보정 (배선 후 필수)

5% 저항이라 같은 전압에서도 개체마다 ±8% 편차가 난다. 배선 직후 다음을 수행한다.

1. 멀티미터로 팩 실제 전압 측정
2. 그때의 ADC 원시값 기록
3. `실제전압 ÷ ADC값` 스케일 계수를 팩별 상수로 저장

만충 근처와 중간 방전 상태 2~3점만 잡아도 충분하다. 거리센서 LUT 작업과 같이 하면 된다.

## 6. 제어선 풀다운 회로

```text
STM32 GPIO ──────────┬─────────→ DFR0601 제어 입력
(PWM 4 + INA/INB 8)   │
                    [10kΩ]
                      │
                     GND (스타 접지)
```

**STM32 리셋·부팅 중 GPIO는 하이 임피던스(Hi-Z)다.** 풀다운이 없으면 그동안 드라이버 입력이
뜬 상태가 되어 모터가 임의로 돌 수 있다. PWM만 내려도 정지하지만(DFR0601 논리표상 PWM=0이면
정지), 방향핀까지 전수 적용해 상태를 확정한다.

## 7. 저전압 보호 임계값 (3S LiPo)

| 전압 | 셀당 | 동작 |
|---|---|---|
| 12.6V | 4.20V | 만충 |
| 11.1V | 3.70V | 공칭 |
| **10.5V** | **3.50V** | **경고** — 대시보드 경고 표시 |
| **9.9V** | **3.30V** | **정지** — STM32 자체 정지 래치 |
| 9.0V | 3.00V | 절대 하한. 여기 도달하면 이미 팩 손상 |

**두 팩 중 하나라도** 임계값에 걸리면 동작한다. STM32가 직접 판단하므로 Nano와 통신이
끊겨 있어도 스스로 모터를 끊을 수 있다 — 300ms 통신 페일세이프에 이은 전원 계층 보호다.

## 8. 빵판(브레드보드) 사용 지침

**저전류 회로는 빵판으로 해도 된다.** 분압 전류는 252µA, 제어신호는 µA급으로 빵판 정격
(접점당 1~2A)의 0.02% 수준이다.

**절대 빵판에 올리면 안 되는 것: 모터 전원(P+/P−, 최대 13A)과 배터리 주회로.** 접점이 녹는다.

### 진동 주의 — 실제 로봇에서는 납땜

빵판 접점은 진동에 약한데 이 로봇은 벽면을 타며 계속 진동한다.

- **분압 접점이 튀면** → ADC 값이 널뛰어 저전압 오탐지로 모터가 멈춘다
- **풀다운 접점이 떨어지면** → 그 핀이 뜬 상태가 되어 **풀다운을 단 목적 자체가 무효**가 된다

→ **벤치 시험은 빵판, 로봇 탑재는 납땜 또는 터미널 블록.** 최소한 풀다운 12개만이라도
고정 결선으로 옮긴다.

## 9. 조립·첫 전원 인가 순서

1. **모든 스위치 OFF, 배터리 미연결** 상태에서 배선
2. 스타 접지부터 결선 — 굵은 선 먼저
3. 제어선(PWM·INA·INB) + 풀다운 12개
4. 분압 회로 2세트 (배터리 미연결 상태)
5. **멀티미터 확인**: `P+ ↔ GND` 도통 없음 / `3V3 ↔ GND` 도통 없음
6. STM32만 USB로 급전해 펌웨어 동작 확인 (모터 전원 없이 PWM 파형 확인 가능)
7. **배터리 연결 전** 분압 출력을 멀티미터로 확인 — 배터리 대신 파워서플라이 12V를 넣고
   분압 노드가 **2.5V 부근**인지 볼 것. 3.3V를 넘으면 즉시 중단
8. 파워서플라이 **전류 제한 1A**로 모터 전원 인가 → 정상이면 올림
9. 마지막에 배터리로 교체

**7번을 건너뛰지 말 것.** 분압을 잘못 꽂아 12.6V가 ADC로 직접 들어가면 STM32가 죽는다.

## 10. 안전 주의

- **12V는 감전 위험이 없지만 화재 위험은 있다.** LiPo 단락은 수백 A를 순간적으로 흘린다.
  배선 중에는 반드시 배터리를 분리한다
- LiPo는 부풀거나 찍히면 사용 중단. 충전은 반드시 밸런스 충전(아이맥스 B6)
- **두 팩의 충전 상태를 맞춰서 사용한다.** 한쪽만 만충이면 방전 종료 시점이 어긋난다
- 시연·시험 전 두 팩 모두 만충 확인을 절차로 고정

## 11. 미확정

- **PB1의 모포 헤더 물리 핀 번호** — 보드 실크스크린으로 확인 후 여기 기록
- 분압 스케일 계수 (팩별) — 배선 후 실측
- 저전압 임계값의 실제 동작 검증 — 파워서플라이로 전압을 낮춰가며 확인
- 실제 소비 전류·구동 시간 — 조립 후 실측 ([[08. 남은과제]])
- 로봇 탑재 시 배선 고정 방식 (납땜/터미널블록/커넥터) — 기구 조립과 함께 결정
