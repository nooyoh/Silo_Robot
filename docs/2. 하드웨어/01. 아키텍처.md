# 아키텍처

사일로봇은 실시간 모터 제어, 로봇 측 통신·영상, 균열 추론, 작업자 관제를 서로 다른 장치로 분리한다. 각 장치는 검증된 통신 경로로 연결하며, 실물 연결 여부와 코드 구현 여부를 구분해 기록한다.

## 시스템 구성

| 계층 | 장치 | 현재 역할 |
|---|---|---|
| 실시간 제어 | STM32 | 모터 4채널 PWM·방향 제어, 좌·우 엔코더 계수, 거리센서·배터리 ADC 입력, 비상정지와 통신 타임아웃 처리 |
| 로봇 브리지 | Jetson Nano B01 | STM32 UART 연동, ROS2 토픽 변환, CSI 카메라 RTSP 송출, RPi 명령 중계 |
| 균열 탐지 | Jetson Orin Nano | RTSP 영상 수신, YOLO 계열 균열 탐지, 탐지 좌표·신뢰도·기록 전송 |
| 관제 단말 | Raspberry Pi 4 | 7인치 터치 UI, 영상·상태 표시, 수동 조작, 반자동 경로 생성, 점검 기록 조회 |

## 연결 구조

- RPi ↔ Nano: WebSocket으로 조작·상태·경로 명령을 교환하고 RTSP 영상을 수신한다.
- Nano ↔ STM32: USB CDC 가상 COM 포트의 UART 프로토콜로 모터 명령과 텔레메트리를 교환한다.
- Nano → Orin: 카메라 RTSP 스트림을 제공한다.
- Orin → RPi: 균열 탐지 결과와 화면 표시용 정보를 WebSocket으로 전송한다.
- 장치 간 IP 연결은 현장 네트워크 또는 Tailscale 기반 사설 연결을 사용한다.

## 현재 실물 상태

- STM32, 모터 드라이버 4채널, 모터 4개, 좌·우 엔코더, Nano와 CSI 카메라의 기본 연동은 확인했다.
- Nano의 RTSP 영상을 RPi 관제 화면에서 수신하는 것까지 확인했다.
- IMU는 연결 경로와 파서가 준비되어 있으나 실제 장착 방향과 Z축 부호를 포함한 종단 검증이 남아 있다.
- 거리센서 3개와 배터리 전압 측정 회로는 핀과 회로가 정해졌지만 아직 실물 배선·보정하지 않았다.
- 최종 프레임 장착, 배선 고정, 벽면 주행 및 안전정지 시험이 남아 있다.
