# 센서-비전

주행 위치 추정과 부착 위험 판단에는 엔코더·IMU·거리센서를 사용하고, 균열 점검 영상은 Nano의 CSI 카메라에서 Orin과 RPi로 전달한다. 아래 상태는 코드 구현과 실물 검증을 분리해 표시한다.

## 센서 구성과 상태

| 항목 | 연결·처리 방식 | 현재 상태 | 남은 검증 |
|---|---|---|---|
| 좌·우 엔코더 | STM32 TIM1·TIM5로 계수하고 Nano에 텔레메트리 전송 | 두 채널 계수 및 주행 방향 확인 | 양쪽 `count/m` 실측, 직진 오차와 부호 재확인 |
| WT901C IMU | Nano GPIO UART(`/dev/ttyTHS1`)에 3.3 V TTL로 직결하고 WIT 프레임 파싱 | 소프트웨어 입력 경로 구현 | 실물 장착 방향, Z축 부호, 정지 바이어스와 주행 중 값 검증 |
| GP2Y 거리센서 3개 | STM32 ADC 3채널 입력(핀은 [[2. 하드웨어/05. 배선도]]만 참조) | 핀·프로토콜·LUT 구조 확정 | 실물 배선, 기준 거리별 ADC 측정, LUT 보정 |
| 배터리 전압 | STM32 ADC로 좌·우 구동계 LiPo 두 팩을 각각 분압 측정 | 회로·핀과 프로토콜 필드 확정 | 실물 배선, 분압비·보정값·저전압 임계값 시험 |

엔코더는 현재 실측상 전진 시 카운트가 감소하는 구성으로 처리한다. 최종 배선과 바퀴 장착 후 `verify_signs`와 1 m 직진 시험으로 다시 확정한다.

## 카메라와 영상 전송

- Jetson Nano B01의 CSI 포트에 Raspberry Pi Camera Module 2(IMX219)를 연결한다.
- Nano에서 GStreamer 기반 RTSP 720p30 스트림을 송출하고, RPi 관제 화면에서 실시간 수신되는 것을 확인했다.
- 카메라의 최종 장착 위치·각도·조명 반사 조건은 기구물 조립 후 확정한다.
- 기본 렌즈, 3.6 mm, 6 mm 후보를 실제 촬영 거리와 시야각으로 비교한다.
- COB LED 조명은 균열부 조도를 확보하기 위한 구성으로, 철판 반사와 그림자를 포함한 실물 촬영 시험이 필요하다.

## 균열 탐지 파이프라인

- Orin이 Nano의 RTSP 영상을 입력받아 YOLO 계열 모델로 균열 후보를 탐지하도록 구성했다.
- 탐지 결과는 좌표, 신뢰도, 프레임 정보 형태로 RPi에 전달하고 점검 화면과 기록에 반영하는 구조다.
- Google Colab Pro는 학습 환경으로 구매했으나 실제 학습 완료·Orin 실시간 추론·정량 성능 검증은 아직 완료되지 않았다.

## 안전 판단에 사용하는 값

- 거리센서 3점의 상대 변화로 벽면과의 밀착 불균형을 판단한다.
- IMU의 각속도·자세 변화는 급격한 기울기 변화나 이탈 징후를 보조 판단하는 데 사용한다.
- 벽면과 천장에서는 절대 Roll·Pitch 값만으로 정상·위험을 구분하기 어려우므로 거리 변화와 동적 IMU 값을 함께 사용한다.
- 위 판단 로직은 설계와 코드 경로가 마련된 상태이며 실물 벽면에서 임계값과 안전정지 동작을 검증해야 한다.
