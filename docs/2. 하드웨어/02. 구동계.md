# 구동계

궤도(무한궤도)형 좌/우 독립구동. 모터 4개(좌/우 각 2개)를 STM32가 모터 드라이버 2개(각 2채널)로
실시간 PWM 제어한다. 상세 제어 로직은 [[3. 소프트웨어/01. STM32]],
**실물 결선은 [[2. 하드웨어/05. 배선도]]가 정본** 참조.

## 구성
- 좌/우 궤도 각 2개, 총 모터 4개
- 모터 드라이버 2개(DFR0601, -12A, 듀얼채널) — 드라이버 1개당 한쪽 궤도(모터 2개) 담당
- 엔코더: 4개 중 좌/우 각각 앞쪽 모터에만 장착 — **나머지 2개는 엔코더 고장이라 미사용**
- 장착 방향: 웜기어 모터가 누워서, **같은 쪽(좌끼리·우끼리) 앞뒤 모터의 엔코더 단이 서로
  마주보게** 장착됨. 마주보게 달렸어도 **현재 배선에서 같은 쪽 두 모터는 같은 방향으로 돈다**
  (2026-08-22 실물 확인) — 방향 보정이 이미 배선에 반영돼 있음. 펌웨어는 같은 쪽 두 모터에
  동일 신호를 보내므로, 재장착 시 이 정렬이 깨지면 두 모터가 서로 싸운다
  ([[2. 하드웨어/05. 배선도]] §2·§8)

## 스펙
- 모터: 웜기어 엔코더 모터 WGM40-3150-1280E, 12V, 감속비 1/290 ([[05. 부품표]] 2025년
  해운물류 구매분, 2026년에도 동일 사용)
- 감속비 1/290 사양: 무부하 27RPM·0.3A, 정격부하 20RPM·1.6A·46kg·cm·19.2W,
  스톨 70kg·cm·6.5A, 기동전압 2V (제조사 사양표 기준)
- 엔코더: AB 2상 증분형, 모터축 기준 16PPR, DC 3.3V/5V, 100kHz, XH2.54 6핀
  ([[4. 자료/02. 모터 자료/2026-08-16_WGM40-3150-1280E_사양-엔코더-핀맵]])
- 모터 드라이버: DFR0601, -12A, 듀얼채널 ([[05. 부품표]])

## 실측 (2026-08-18, 무부하 벤치)
- **모터 4개 전부 회전 확인** — 첫 실물 구동 성공
- `throttle=20`에서 이미 회전 → **데드존 20% 미만**, 정확한 값은 재측정 필요
- 방향 전환 시 순간 전류 **1.7A** (무부하 기준. 등반 부하·스톨은 훨씬 큼 — 사이징 근거로 쓰지 말 것)
- 좌우 배선: 8/18엔 한쪽이 뒤집힌 상태였으나 **현재는 정렬 완료** — `turn=+`(우회전) 명령에서
  좌 전진·우 후진 확인(2026-08-22). 재배선하면 [[2. 하드웨어/05. 배선도]] §8 검증 절차를 다시 돌릴 것

## 미확정
- 데드존 정확값(20% 미만인 건 확인)·최대 듀티비 — 부하 상태에서 재측정 필요
- 목표 등반 속도, 적재 하중 목표 — [[91. 질문지]] H절
- 엔코더 STM32 입력 핀·A/B 방향 — 실물 연결 시 확정
