# 영상·보고서 촬영 체크리스트

촬영 전 렌즈를 닦고 가로 16:9·1080p30 이상으로 고정한다. 모든 영상은 동작 전후 2초씩 남기고,
전원장치의 AC 단자는 보호커버를 씌운 뒤 촬영한다.

## 1. 영상용 필수 컷

- [ ] 로봇 전체 45도 히어로 숏 8초, 정면·측면 각 5초
- [ ] 좌우 궤도, 모터 4개, 프레임 관절·장력조절부 근접 이동 숏
- [ ] Nano·STM32·DFR0601 두 장 전체 전장 탑뷰
- [ ] 받침대 위 전진·후진·좌회전·우회전 각 2초와 모터 4개 동시 반응
- [ ] RPi 조작 손과 실제 궤도 반응이 한 화면에 보이는 컷
- [ ] 저속 주행 중 RPi 비상정지 → 완전 정지 → 정지 래치 화면을 끊지 않고 촬영
- [ ] 카메라 피사체와 RPi RTSP 화면이 동시에 보이는 컷(카메라 연결 후)
- [ ] RPi 0.5 × 0.5m 계획 화면과 로봇 전체가 같이 보이는 `demo-square` 10초 원테이크
- [ ] 계획 UI·기록 카드는 실제 동작할 때만 촬영하고, 실물 추종 전이면 `시뮬레이션` 자막 사용
- [ ] AI 팀원 영상 12~14초: `AI 단독 시험 / 로봇 실시간 연동 전` 자막
- [ ] 마지막 정지 히어로 숏 5초

`demo-square` 영상 자막은 **0.5 × 0.5m 계획 화면 연동 주행 시연(모터 시간제어)**이다.
`0.5m 정밀주행`, `자율 경로 추종`, `커버리지 주행 성공`으로 쓰지 않는다.

## 2. 보고서용 필수 사진

- [ ] 전체 로봇: 상면·정면·측면·45도, 가로 고해상도 각 1장
- [ ] 좌우 궤도와 모터 4개가 모두 보이는 구동부 전체
- [ ] 궤도 관절·장력조절부·프레임 결합부 근접
- [ ] Nano·STM32·브레드보드·DFR0601 ×2가 한눈에 보이는 전장 탑뷰
- [ ] STM32 3V3→드라이버 VCC, 공통 GND, 12V P+/P−가 식별되는 배선 근접
- [ ] 드라이버 `STATE` LED와 실제 출력 중 채널 LED가 함께 보이는 사진
- [ ] PSU +V/−V Y분기와 두 드라이버 전원 입력(AC 단자 보호커버 장착 후)
- [x] RPi 대시보드의 Nano 연결·안전상태 화면
- [x] RPi 조작과 궤도 반응이 동시에 보이는 통합 사진
- [ ] 비상정지 표시 화면과 멈춘 로봇
- [ ] CSI 카메라 실물과 RTSP 관제 화면(연결 후)
- [ ] RPi 계획 화면과 사각 주행 시험 배치 전체
- [ ] CAD/출력부품/실물 프레임 비교 사진과 팀 작업 과정 사진

## 3. 촬영 후 바로 확인

- [ ] 모터 4개가 모두 움직이는 장면이 선명한가
- [ ] 비상정지 버튼을 누른 순간과 완전 정지가 한 클립에 있는가
- [ ] 대시보드 글자와 LED 상태가 확대 없이 읽히는가
- [ ] 사람 얼굴·개인정보·Wi-Fi 비밀번호·터미널 비밀번호가 노출되지 않았는가
- [ ] 흔들림·초점 이탈·세로 촬영·로봇 잘림이 없는가
- [ ] 원본을 기능명으로 즉시 백업했는가 (`01_hero`, `02_drive`, `03_estop`, `04_square` 등)

## 4. 완료 표현 기준

현재 완료형으로 써도 되는 것은 **기구·전장 조립, RPi→Nano→STM32 통신, 수동 모터 4개 구동**이다.
실제 촬영 후에는 비상정지도 완료형으로 추가할 수 있다. 아직 완료형으로 쓰면 안 되는 것은
실물 자율 경로 추종, 정확한 1m 오차, 벽면 등반·부착, 거리·IMU 안전판정, AI 실시간 통합이다.
