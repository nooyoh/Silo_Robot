# 09. 실기 준비물 — 학교 테스트 챙길 것

**일회용 목록.** 시험 끝나면 결과만 [[1. 로그]]·[[03. 트러블슈팅]]에 옮기고 **이 파일은 지운다.**
그래서 예외적으로 체크박스를 쓴다 — 프로젝트 진행률 추적이 아니라 그날 챙길 물건 목록이다
(규약 §4가 막는 건 진행관리 요소지 준비물 메모가 아니다).

**오늘 시험 범위**: STM32 펌웨어 실기 검증(PWM 4채널·방향·램프·비상정지·타임아웃) +
모터 구동. 벽면 등반은 장소 조건([[91. 질문지]] Q26) 확인 전까지 **무부하 회전 + 평면 주행까지**.

---

## 1. 없으면 시험 자체가 안 되는 것 ⚠

- [ ] **NUCLEO-F401RE 보드**
- [ ] **USB 케이블 (ST-LINK용, Mini-B)** — 전원·펌웨어 write·VCP 통신 3역할 겸용.
      **이거 하나 빠지면 오늘 아무것도 못 한다**
- [ ] **노트북 (Victus)** + **충전기**
- [ ] **모터 WGM40 ×4** (또는 최소 1~2개, 무부하 회전만 볼 거면)
- [ ] **모터 드라이버 DFR0601 ×2**
- [ ] **점퍼 케이블** — M/M, M/F, F/F 3종 (핀맵상 PWM 4 + 방향 8 = **최소 12가닥 + GND**)
- [ ] **브레드보드** (핀맵이 Arduino 헤더 기준이라 있으면 훨씬 빠름)

## 2. 전원 계통

- [ ] **학교 파워서플라이** — 리포 못 받을 가능성 높아 이게 주력. **12V / 최소 3~4A 이상** 확인
      (모터 정격 1.6A × 4 = 6.4A, 스톨 6.5A/개)
- [ ] 리포 11.1V 2200mAh ×2 (받을 수 있으면)
- [ ] **아이맥스 B6 충전기 + 파워서플라이** (리포 쓸 경우)
- [ ] XT60 케이블
- [ ] 굵은 전선 (8AWG/12AWG), 압착단자
- [ ] **퓨즈 + 홀더** (32V 20A) — 배선 실수 시 모터드라이버 살리는 보험
- [ ] 토글 스위치 (전원 차단용)

> **전원 주의** — DFR0601의 **제어부 VCC(3.3V)** 와 **모터 전원 P+/P-** 를 혼동하면 보드가 죽는다.
> NUCLEO는 USB로 급전하고, 모터 전원은 완전히 분리하되 **GND는 반드시 공통으로 묶는다.**

## 시험 중 반드시 기록해올 것

이걸 안 적어오면 다음 세션에서 또 막힌다. **숫자로** 적어올 것.

1. **데드존 듀티비** — 모터가 실제로 돌기 시작하는 최소 %
2. **최대 듀티비** — 100%에서 이상 없는지, 발열·소음
3. **무부하 회전수** — 사양표 27RPM과 실제 차이
4. **엔코더 A/B상 실제 신호** — 어느 핀이 A인지, 전압 레벨(3.3V/5V), 회전당 펄스 수
5. **소비 전류** — 무부하 / 부하 시 (파워서플라이 표시값)
6. **PWM 파형** — 20kHz 제대로 나오는지 오실로스코프 사진
7. **비상정지·타임아웃** — 케이블 뽑았을 때 300ms 안에 멈추는지
8. **조립 진척도 %** — [[91. 질문지]] Q10, 한이음 보고서 필수 항목
