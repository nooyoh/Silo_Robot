# 1차 핀맵 (실물 배선 전 잠정)

NUCLEO-F401RE의 Arduino 헤더만 사용해 브레드보드 배선을 단순화한 핀맵입니다.
실물 조립 때 커넥터 접근성에 문제가 있으면 CubeMX와 `silo_board_config.h`를 함께 변경합니다.

## 통신·센서

| 기능 | MCU 핀 | NUCLEO 핀 | 비고 |
|---|---|---|---|
| ST-LINK VCP TX | PA2 | D1 | USART2_TX, 115200bps |
| ST-LINK VCP RX | PA3 | D0 | USART2_RX |
| 거리센서 1 | PA0 | A0 | ADC1_IN0 |
| 거리센서 2 | PA1 | A1 | ADC1_IN1 |
| 거리센서 3 | PA4 | A2 | ADC1_IN4 |

## 모터 드라이버

DFR0601 채널마다 `PWM`, `INA`, `INB`가 필요합니다. PWM은 20kHz로 설정합니다.

| 모터 | 역할 | PWM | INA | INB |
|---|---|---|---|---|
| M1 | 좌측 앞(엔코더 모터) | PB4 / D5 / TIM3_CH1 | PA8 / D7 | PA9 / D8 |
| M2 | 좌측 뒤 | PC7 / D9 / TIM3_CH2 | PA10 / D2 | PB5 / D4 |
| M3 | 우측 앞(엔코더 모터) | PB6 / D10 / TIM4_CH1 | PA5 / D13 | PA6 / D12 |
| M4 | 우측 뒤 | PB10 / D6 / TIM2_CH3 | PA7 / D11 | PB8 / D15 |

권장 연결은 DFR0601 #1의 채널 1/2에 M1/M2, DFR0601 #2의 채널 1/2에 M3/M4입니다.

## DFR0601 논리

| INA | INB | PWM | 출력 |
|---|---|---|---|
| 0 | 0 | X | 정지 |
| 0 | 1 | duty | 정방향 |
| 1 | 0 | duty | 역방향 |
| 1 | 1 | X | 플로팅 |

방향 전환 전 PWM을 0으로 낮춰야 합니다. 실제 HAL 출력 계층에는 역전 인터록/감속 램프를 둡니다.

## 아직 배정하지 않은 핀

- 좌·우 앞 모터 엔코더: 커넥터의 A/B상·전원 규격과 정상 채널을 실물로 확인한 뒤 배정
- DFR0601 STATE는 외부 신호핀이 아니라 보드 상태 LED이므로 MCU 입력으로 배정하지 않음
